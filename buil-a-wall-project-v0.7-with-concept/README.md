# buil a wall — прототип 0.7

Полный проект для собственного Git-репозитория. Браузерная 2D-игра: строительство шести стен с нуля, доход, улучшения с таймером и защита города от титанов.

## Быстро поиграть

В архив включена готовая версия: откройте **outputs/last-bastion.html** в браузере. Интернет и сервер не нужны. Нажмите «Начать играть» на главном экране.

## Сборка из исходников

Для разработки нужны Node.js и npm. Внешних пакетов нет, поэтому npm install не требуется. Выполняйте команды из корня распакованного проекта:

~~~sh
npm run build
npm test
npm run check
npm start
~~~

После npm start откройте http://127.0.0.1:8765. Сервер доступен только на вашем компьютере; остановка — Ctrl+C. Если порт занят, остановите другую копию сервера.

При изменении исходников повторите npm run build и обновите страницу. Сервер не делает автоматическую пересборку.

Суффиксы v04 в именах клиентских файлов исторические: они содержат текущую версию 0.7. Редактируйте эти исходники, а не автоматически созданный work/client.js или outputs/last-bastion.html.

npm run balance сохраняет новый отчёт в work/balance-results.json. В outputs/balance-results.json приложен результат последнего прогона. Механика и правила описаны в outputs/Механика-и-результаты.md. Промпт стартовой иллюстрации — outputs/buil-a-wall-scene-prompt.md; иллюстрация создана через imagegen.

## Перенос в Git

Распакуйте архив, откройте корневую папку как проект и создайте в ней репозиторий. Архив содержит package.json, README.md, .gitignore и .gitattributes. История Git, адрес удалённого репозитория и учётные данные не включены.

~~~sh
git init
git add .
git commit -m "Initial playable prototype"
~~~

Затем подключите свой удалённый репозиторий. Сгенерированные work/client.js и outputs/last-bastion.html исключены из Git: после клонирования они создаются командой npm run build. Сам архив уже содержит готовый HTML для игры.

## Игровая версия

- Сцена 1920 × 1080 масштабируется под окно. Поле занимает верхние 70%, город — нижние 30%.
- На старте $20 и шесть пустых зелёных точек. Стена стоит $20 и приносит $5/сек.
- После шестой стены открываются улучшения, и через 10 секунд приходит первый титан.
- Каждое улучшение занимает 2 игровые секунды. Характеристики меняются по завершении; прерванное прямое улучшение возвращает оплату.
- WASD / стрелки / клик — движение; 1–6 — выбор стены; E — магазин; F — установка; R — ремонт; P / Space — пауза.

Это браузерный прототип. Roblox-кода, сетевого режима, звука и сохранения забега пока нет.

## Концепт игры

Полная идея, игровой цикл, обучение, прогрессия, визуальное направление и вопросы для плейтеста собраны в [CONCEPT.md](CONCEPT.md). В документ включена иллюстрация стартового экрана. Актуальные правила отделены от прежних вариантов и предложений на будущее.
