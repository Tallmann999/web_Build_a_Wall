# buil a wall — прототип 0.14

Полный проект для собственного Git-репозитория. Браузерная 2D-игра: строительство шести стен с нуля, доход, улучшения с таймером и защита города от титанов.

## Быстро поиграть

В архив включена готовая версия: откройте **outputs/last-bastion.html** в браузере. Интернет и сервер не нужны. Нажмите «Начать играть» на главном экране.

## Сборка из исходников

Для разработки нужны Node.js и npm. Внешних пакетов нет, поэтому npm install не требуется. Выполняйте команды из корня распакованного проекта:

~~~sh
npm run build
npm test
npm run check
npm start
~~~

После npm start откройте http://127.0.0.1:8765. Сервер доступен только на вашем компьютере; остановка — Ctrl+C. Если порт занят, остановите другую копию сервера.

При изменении исходников повторите npm run build и обновите страницу. Сервер не делает автоматическую пересборку.

## Перенос в Git

Распакуйте архив, откройте корневую папку как проект и создайте в ней репозиторий. Архив содержит package.json, README.md, .gitignore и .gitattributes. История Git, адрес удалённого репозитория и учётные данные не включены.

~~~sh
git init
git add .
git commit -m "Initial playable prototype"
~~~

Затем подключите свой удалённый репозиторий. Сгенерированные work/client.js и outputs/last-bastion.html исключены из Git: после клонирования они создаются командой npm run build. Сам архив уже содержит готовый HTML для игры.

## Игровая версия

- Сцена 1920 × 1080 масштабируется под окно. Поле занимает верхние 70%, город — нижние 30%.
- На старте $20 и шесть пустых зелёных точек. Стена стоит $20 и приносит $5 раз в 2 секунды.
- После шестой стены открываются улучшения, и через 10 секунд приходит первый титан.
- Каждое улучшение занимает 2 игровые секунды. Характеристики меняются по завершении; прерванное прямое улучшение возвращает оплату.
- WASD / стрелки / клик — движение; 1–6 — выбор стены; E — магазин; F — установка; R — ремонт; P / Space — пауза.

Это браузерный прототип. Roblox-кода, сетевого режима, звука и сохранения забега пока нет.

## Изменения 0.9

Возвращена исходная обложка start-scene.png и прежняя стартовая кнопка. Купюры поднимаются только над своей стеной на 44 пикселя и исчезают; кошелёк подсвечивается и показывает сумму пополнения. Базовая выплата — раз в 2 секунды, сумма выплаты прежняя. Во вкладке магазина «Доход» покупка за $5000 открывает выплаты раз в секунду для всех стен до конца забега. Покупка одноразовая, не занимает рюкзак и сохраняет накопленный доход. Все подсказки и цены обновляются вместе с режимом.

Из-за возвращения оригинальной PNG-обложки без изменений полный HTML теперь занимает около 4,54 МБ; игровые атласы по-прежнему занимают 1,09 МБ. `npm test` проверяет также новую экономику, `npm run check` — привязки графики, возврат исходной обложки и покупку улучшения через UI. Размер 1,54 МБ в разделе 0.8 относится к предыдущей версии с другой обложкой.

## Изменения 0.10

- После шестой стены подсказка со стрелкой предлагает выбрать скорость ×2. Закрывается вручную или после выбора ускорения, сбрасывается в новом забеге.
- Маршруты титанов стали ярче: крупные стрелки ведут к стене, после прорыва — к ратуше.
- В городе остались только ратуша и магазин; дома, кузница, склад и пекарня убраны.
- HP всех титанов увеличены на 50% с округлением до целого, без изменения их урона и наград.
- Раздел «Доход» переименован в «Улучшения». Внутри — единый список улучшений урона пушек и дохода.
- За $5000 можно один раз купить +20% урона всех пушек до конца забега. Бонус сохраняет дробный урон (6 → 7,2), действует на новые выстрелы, улучшенные и восстановленные стены. Покупка независима от улучшения дохода и не занимает рюкзак.

Цитадель: $8500, 6200 HP, 240 урона, $60 за выплату. Глобальные улучшения остаются по $5000. Все счётчики, правила и победный экран обновлены. ## Изменения 0.12

На уровне 9 два титана, перерывы между волнами 12 секунд. Стены подняты на 266 пикселей; магазин и ратуша внизу; рюкзак под кассой. Убраны подписи целей и материалов над стенами. Герой может выходить за стену и собирать случайные золотые сундуки с растущей наградой $40–$2380. До трёх сундуков на поле, срок жизни 40 секунд. Актуальные таблицы и 120 симуляций: [BALANCE.md](BALANCE.md). В сборке 75 спрайтов: два прежних атласа и отдельный маленький WebP сундука.

## Изменения 0.13

Стены опущены до Y=740. Сундуки возникают только на свободной траве, дороги и здания исключены. Титаны выходят из-за горизонта постепенно (голова → тело → шаг на землю), приближаются с увеличением масштаба и останавливаются за стеной на дистанции удара. Отдельные стрелки-цели убраны; маршрут заканчивается у стены. Ремонт показывает круговой прогресс, оставшееся время и молоток с ударами внутри рамки; меню не закрывает счётчик. Добавлен небольшой WebP молотка: 76 используемых спрайтов, графика около 1,12 МБ. Проверены 68 тестов механики, отрисовка и 120 полных симуляций.

## Изменения 0.14

HP всех титанов повышено ещё на 20% относительно 0.13. Частота сундуков снижена на 20% (интервалы ×1,25); награды снижены ровно на 20%, до $32–$1904. Сундук живёт 10 игровых секунд, то есть 5 обычных секунд на ×2. Прямое улучшение и установка комплекта требуют близости инженера (85 мировых единиц) и полностью починенной стены. Красная рамка в меню сообщает причину блокировки. Разрушенную стену можно восстановить в текущем материале, затем улучшить. Ограничения проверяются также во время установки; отмена возвращает оплату или сохраняет комплект. 74 проверки механики, проверки UI и таймера ×2, 120 автоматических забегов. Архив для itch.io перезаписывается по прежнему пути outputs/build-a-wall-v0.13-itch.zip; внутри версия 0.14.
